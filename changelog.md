# Changelog

## [1.0.2] - 21/09/2026

### Updated

The random pertubation for each atom is now chosen by uniformly sampling a 3D ball.

## [1.0.1] - 14/09/2026

### Added

Functionality for all space groups.
This works by finding all the atom sites in the motif when the file is input.
Note that the output is always in the P1 space group.

## [1.0.0] - 10/09/2026

### Released

First version of the "Disguise a Crystal" app.
